Recover administrator access

This one-time recovery restores the existing administrator account. It does not create another administrator or change any department accounts.

Only continue if you control the Render service and its production database. The email and password you enter will replace the current administrator’s OptiGo sign-in credentials. This does not change a Gmail password.

Use the value you set in the Render service environment as ADMIN_RECOVERY_KEY.

The recovery key is checked by the OptiGo API, is never saved by this page, and the backend permanently disables this operation after one successful recovery.
